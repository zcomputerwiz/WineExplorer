## Implement the real slice

1. Define `IStorageFolderStatics` from the public interface contract using Wine
   IDL conventions; the local Wine file currently only forward-declares it.
   Update the `StorageFolder` runtime class statics metadata and register that
   class in this DLL. Use public IID/method facts, no copied Microsoft
   implementation or SDK source. Preserve Wine LGPL notices.
2. Add a class factory exposing the required statics interface with correct
   reference/QueryInterface identity and class/error behavior. Preserve existing
   stream class registration and activation.
3. `GetFolderFromPathAsync` must run real directory validation/opening using
   the caller's ordinary access rights and return a real `IStorageFolder` plus
   `IStorageItem`. Keep an owned directory handle and bounded path state; use
   the observed path/name/metadata contract. A missing path or file-as-folder
   returns the observed error through the operation, never Completed/success
   with a dummy object. Do not bypass ACLs, broaden access or invent package
   identity/containment.
4. Reuse the module's existing `async_info_create` / callback and lifetime
   machinery, adding a narrowly typed wrapper (there is no existing generic
   `async_operation_inspectable_create` export in this module). Supply the typed
   operation IID generated by WIDL, not a guessed interface layout. Preserve
   parameter/instance lifetime until completion; completion/cancel/GetResults
   errors must follow the existing helpers and native observations.
5. Implement the observed read-only `IStorageItem` metadata needed to establish
   this is a real folder. Unsupported folder/file mutation/enumeration methods
