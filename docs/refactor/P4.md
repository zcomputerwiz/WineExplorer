# P4 repository restructure

In progress. P3b is accepted; installed runtimes still use accepted P3.

The remaining project DLLs/programs, wexhost header and theme definitions
have moved to src. The first relocation includes 324 tracked paths. Original
licenses and bytes are preserved; desk.rc lacked a project license, which
the existing license tool now adds without changing its resource definitions.
Public asset generation and its manifest follow the owned source locations.
The real, unchanged wine-11.19 annotated tag is now published on the fork.

Assembly uses scripts/assemble.py, called by assemble.sh. Three deliberately
replaced stock stubs are listed in src/stock-replacements.txt: desk.cpl,
wlanui and wmplayer. Their original directories are preserved under
build/assembly-stock before linking project implementations. Replacement
requires a pristine standalone Wine checkout, with no edited, untracked or
ignored files in that module. Other nonempty collisions remain errors.
The safety fixture passes pristine preservation/idempotence and rejection
of edited, extra-file and undeclared destinations.

The prototype is /srv/protonexplorer/wex-refactor-p4. Its first ownership
build is pending; this is not the fresh recursive-clone acceptance yet.
Remaining work includes the Wine gitlink, recursive VM source sync,
private overlay routing, installer/tool paths, fresh recursive clone and
full build/install/ISO/interactive installer/dev-session checks. P5 extension
assessment and P6 rebase drill follow P4.
