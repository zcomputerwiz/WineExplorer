# P3 Explorer plugin

P3 acceptance passes; see P3_TEST_REPORT.md for exact evidence and limits.
The implementation in src/dlls/wexshell
comes solely from committed public source c9f9440d, including its existing
Wine/ReactOS/project license notices and open resources. It keeps the shell
subsystems together. No local resource overlay was copied.

The shared wexshell.h defines version 1 start/command/stop signatures. The DLL
owns its resource instance; moved module-handle references use that instance.
The startup code subclasses the existing desktop and initializes the existing
shell features in their original order. Stock Explorer retains desktop
creation, clipboard/display setup, shell COM registration and the message
loop. Its validated host hooks are now in the main source and retained fork.

The plugin's module and full build pass in a separate source/build at
/srv/protonexplorer/wex-refactor-p3. It reuses independent copies
of P2 objects; P2 source/build remain untouched. Log:
/srv/protonexplorer/p3-build.log. The public runtime was installed only into a
staging directory on this VM; relocated runtime checks pass. Do not claim plugin
acceptance until the host hook, missing-plugin behavior, screenshots, dev
session, composition probes and installer checks have been exercised.

The original host is now restored with minimal hooks: versus fork master,
desktop.c has 34 additions/7 removals and explorer.c has 5 additions. The
retained branch is pushed through 43c797e7e617814e4c5aa2b7615fe085eabd4da1.
Moved files were removed from programs/explorer; assembler links src into
Wine before configure. Its repeated-link check and linked module build pass.
VM sync and resource generation now use the new source paths, including
mapping local-only artwork into the plugin without putting it in this repo.

The full build, tray geometry and eight native-dialog cases pass. Enabled and
disabled DLL cases, required exports, incompatible version/null desktop and
desktop commands after other switches pass. The desktop, both Start menus,
My Computer and Turn Off screenshots were inspected against P2. All four
feature captures are pixel-identical above the taskbar; the clock differs.
The first physical-click capture missed the Classic menu, so the maintained
probe opens it via the actual Start button procedure and checks visibility.
The dev VM build was installed and its live Luna session restarted; process
maps confirm that the shell runs from wexshell.dll. Old future-dated generated
artifacts were removed, the build repeated successfully, and no future files
remain. The guest clock was not changed. Composition and installer checks
now pass. The public-resource ISO and scripted interactive installation pass,
including authenticated/passwordless logins and prefix isolation. Composition
input/blend/capture checks match P2, and five enable/disable cycles pass.
The final grouped-caption resource-owner adjustment compiles and a crowded
