# P2 retained stock-Wine series

P2 acceptance passes on [wineexplorer/11.19](https://github.com/zcomputerwiz/wine/tree/wineexplorer/11.19).
Assembled source equality and the full 64-bit build pass. The isolated desktop
smoke check passes: two tray icons have no overlaps or out-of-bounds windows,
and all eight native-dialog placement cases pass. The Classic desktop
screenshot was inspected. Broader screenshot/feature comparisons are required
for P3; this smoke check does not cover themes or every shell feature.

The branch retains the real wine-11.19 release ancestry and the original 72
upstream commits through eba89375a0515957701928faac0f5007ef638b04. This is the
exact stock snapshot identified in P0. Keeping those original commits preserves
their authorship, messages and provenance; each original B item can be dropped
when rebasing onto a release that already contains it. They are indexed by the
P0 path/hunk map rather than relabeled as WineExplorer-authored changes.

The retained series now has 85 commits after that snapshot, through
916ffefabc (see P2_SERIES.json for the full verified hash). Our commits name
their STOCK_CHANGES rows; an additional original upstream backport retains its
original message and author. The complete commit/path ledger is
[P2_SERIES.json](P2_SERIES.json).

The twelve U fixes are retained without their P1 test additions. Forty-seven
X groups cover the desktop/windowing, theme, audio, namespace, operation,
dialog and open-resource changes. Shared shell/theme declarations were split
into separate feature commits. Four H groups preserve the current Explorer,

`scripts/refactor-series.py` exports one hash-verified group of reviewed
hunks, or whole binary files, without introducing full-file blob ids for a
partial text patch. It handles file creation/deletion explicitly. Three
negative checks reject changed revision, file hash and hunk hash inputs.
Its repeatable `--hunk` option selects exact reviewed SHA-256 hunks within a
target, rejecting hashes absent from that target.
The selected-hunk negative check also passes against the refreshed audit.
`scripts/refactor-progress.py` compares actual Git trees and rejects an
unmapped difference. `scripts/refactor-assemble.py` overlays the 436 pure-M
paths from the pinned public Git tree in a temporary index. It checks every
assembled blob and mode against the source, allowing only the twelve pure-N
differences, whose upstream contents remain unchanged. It never modifies the
retained branch or reads local resource overlays. P2_ASSEMBLY.json records
the tree and transfer patch hashes. Equality passes with zero unexpected
differences.
