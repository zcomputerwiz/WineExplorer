# Fluent (Windows 11 style): icon provenance

Generated by `scripts/build_iconpack.py --provenance assets/iconpacks/fluent.json`.

Except the Recycle Bin, every shape is a glyph of Fluent UI System Icons (Microsoft, MIT licence, https://github.com/microsoft/fluentui-system-icons, files `assets/<Name>/SVG/ic_fluent_<name>_<size>_<filled|regular>.svg`). The build recolours each glyph with a flat colour, scales it and places it; nothing else is changed. A "tone" pair is the filled glyph in a light colour under the regular (outline) glyph in a darker colour, which gives the two-tone look. The colours were picked by eye so that each icon resembles the Windows 11 icon of the same slot, compared side by side on a developer's machine. No Windows pixels, outlines or files were used, and no fonts. The Recycle Bin (ids 32 and 33) is the Tela icon theme's user-trash and user-trash-full SVG, edited as listed: its body is given a pale translucent fill and a visible outline, a darker base band is added, and its recycle symbol is recoloured blue; nothing else is changed.

Licence of the pack as a whole: GPL-3.0, because it contains Tela icon theme art (GPL-3.0); the Fluent UI System Icons glyphs in it remain under the MIT licence.
