# Fluent (Windows 11 style): icon provenance

Generated by `scripts/build_iconpack.py --provenance assets/iconpacks/fluent.json`.

Every shape is a glyph of Fluent UI System Icons (Microsoft, MIT licence, https://github.com/microsoft/fluentui-system-icons, files `assets/<Name>/SVG/ic_fluent_<name>_<size>_<filled|regular>.svg`). The build recolours each glyph with a flat colour, scales it and places it; nothing else is changed. A "tone" pair is the filled glyph in a light colour under the regular (outline) glyph in a darker colour, which gives the two-tone look. The colours were picked by eye so that each icon resembles the Windows 11 icon of the same slot, compared side by side on a developer's machine. No Windows pixels, outlines or files were used, and no fonts.
