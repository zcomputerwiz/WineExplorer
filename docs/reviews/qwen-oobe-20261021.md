## Findings / exact fix instructions

### F1 [P2] Reject extra frames and embedded NULs in bridge replies

`src/dlls/wexhost/unixlib.c:2131` and `:2155`: the new review-info and running
parsers require the next character to be newline, but do not require the frame
to end there. The receive paths check only that the last received byte is also
newline. The actual compiled production seam accepts these malformed inputs:

| Mode / received bytes | Actual successful result |
| --- | --- |
| info: `OK 123456 3 0\nEXTRA\n` | `0\|123456\|3\|0` |
| info: `OK 123456 3 0\n\x00EXTRA\n` | `0\|123456\|3\|0` |
| query: `STATUS RUNNING 1 2\nEXTRA\n` | `0\|RUNNING\|1\|2\|\|` |
| query: `STATUS RUNNING 1 2\n\x00EXTRA\n` | `0\|RUNNING\|1\|2\|\|` |
| info: `OK 0 0 0\n` | `0\|0\|0\|0` |

Control `OK 123456 3 0\n` succeeds as expected. Error0 on these malformed frames
contradicts Q6's complete-framing and zero-total/count controls. This is not a
claim of an install/elevation bypass; it is a demonstrated protocol-validation
gap hidden by the current15 bridge tests.

Required repair/proof:

1. Validate the entire byte-counted reply, not merely its C-string prefix.
   Reject embedded NULs, trailing frames/junk, and over-capacity input. Simply
   checking `p[1] == '\0'` is insufficient when an embedded NUL precedes extra
   received bytes. Require exactly one complete protocol response.
2. Require positive review-info package totals/counts. Keep cached0 and progress
   done0 valid; do not blanket-reject all zeros. Progress total must remain valid
   for an actual catalog download and done<=total.
3. Audit START/QUERY/CANCEL response readers for the same byte-length/NUL issue,
   and validate operation IDs with the protocol's intended grammar.
4. Add each frame above to `test_oobe_bridge.py` using its existing `exercise`
   method. Assert a nonzero error/no successful progress or metadata. Preserve
   all existing good frames, exact16GiB boundary, canonical digits and retry
   behavior. Execute the real C seam, not a Python parser stand-in.

Reproduction from an archived snapshot's scripts directory:

```python

BridgeTests.setUpClass()
try:
    case = BridgeTests('test_review_info_parses_totals_and_cache_state')
    print(case.exercise([b'OK 123456 3 0\nEXTRA\n'], mode='info')[0])
    print(case.exercise([b'STATUS RUNNING 1 2\n\0EXTRA\n'], mode='query')[0])
```
