# Which checks a changed path calls for (scripts/lab/wex-test.sh; docs/TOOLING.md, "Targeted runs").
# One rule per line: a glob (bash pattern on the path; "wine:" before it for a path in the Wine tree), then the checks,
# comma separated. The first rule a path matches decides (specific rules go before general ones). Checks:
#   none          nothing beyond what wex-test.sh does anyway (documentation)
#   normalsuite   the normal suite and the broker test (wex-run.sh normalsuite)
#   t1suite       the T1 lab (wex-run.sh t1suite)
#   lab           the lab build and the lab suite (wex-run.sh lab)
#   image         the VM image smoke check: WEX_BATCH_FWS=uefi wex-batch.sh REV NAME rundialog (printed, not run)
#   chain         the whole chain on both firmwares: wex-batch.sh REV NAME (printed, not run)
#   py:FILE       a static test: python3 FILE from the worktree (seconds; needs no build)
#   sh:FILE       a static test: bash FILE from the worktree (seconds; needs no build)
#   gpolab        the GPO lab's installed-machine guests on wexgpo: gpo-lab-run.sh machines (printed, not run)
# A Wine module with a tests folder (dlls/X, programs/X, and WineExplorer's own under src/) always gets its own
# Wine tests, both architectures, without a rule. A path no rule matches gets normalsuite and a note: add a rule.
